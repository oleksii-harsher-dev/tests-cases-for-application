TC-TRANSFER-1 - Успішний переказ коштів на картку з валідними даними

Functional, High Priority, Positive

Preconditions:
1. Користувач авторизований у мобільному банкінгу.
2. У користувача є активна картка з достатнім балансом.
3. Користувач відкрив екран «Переказ коштів».
4. Функція переказу на картку доступна.

Test Data:
Картка відправника: VISA ****3831
Номер картки отримувача: 4444111122223333
ПІБ отримувача: Іваненко Іван Іванович
Сума: 100
Валюта: UAH
Призначення платежу: Test transfer

Test Steps:
1. Переконатися, що картка VISA ****3831 обрана як картка відправника.
2. Натиснути на поле «Картка або телефон».
3. Ввести валідний номер картки отримувача 4444111122223333.
4. Ввести ПІБ отримувача «Іваненко Іван Іванович».
5. Ввести суму переказу 100.
6. Переконатися, що валюта встановлена в UAH.
7. Заповнити поле «Призначення платежу» значенням «Test transfer».
8. Натиснути кнопку «Продовжити».

Expected Result:
1. Поле «Картка або телефон» містить введений номер картки.
2. Поле ПІБ отримувача містить введене значення.
3. У полі суми відображається значення 100.
4. Валюта переказу відображається як UAH.
5. Кнопка «Продовжити» активна.
6. Після натискання кнопки «Продовжити» відкривається наступний етап оформлення переказ з відображенням даних для підтвердження переказу
